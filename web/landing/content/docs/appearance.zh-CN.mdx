用 `⌘,` 打开 **设置**。这是一个标准的 macOS 设置窗口，左侧一列标签页。**外观** 管主题和
应用自身的样子；**终端** 管终端的字体、光标和窗口。

## 主题

Termio 使用 Ghostty 格式的主题，所以 Ghostty 主题生态里的东西都能用。在
**设置 ▸ 外观** 里各选一个浅色和深色主题，Termio 会跟随系统在两者之间切换。

每个槽位都包含内置主题和主题文件夹中的 Ghostty 格式主题。在外观中选择 **深色**，
即可始终使用深色主题。

如果你本来就在用 Ghostty，全新安装时其实不用挑：Termio 首次启动会读取你的
`~/.config/ghostty/config`，直接沿用你在那里选好的字体和主题。

## 获取更多主题 [#getting-more-themes]

打开任意一个主题槽位，即可搜索内置主题并查看配色。要使用截图中的主题，在深色槽位
选择 **Atom One Dark**。

想以你自己的终端为预览，在已有的主题之间切换，打开命令面板（`⇧⌘P`）并选择
**更改主题…**——在列表里上下移动会实时给你打开的终端重新上色，回车保留，Esc 还原。

要加入其他主题，把 Ghostty 格式的主题文件放进：

```
~/Library/Application Support/termio/Themes/
```

**打开主题文件夹** 按钮会直接带你过去，**重新加载** 会在不重启的情况下识别新文件。

## 字体

在 **设置 ▸ 终端** 里选择你 Mac 上任意一款等宽字体，设定字号，如果偏好更重的笔画可以打开 **加粗字形**。
字号也有工作时可用的实时快捷键——`⌘=` 变大，`⌘-` 变小，`⌘0` 还原。

## 光标与窗口

终端标签页还能调光标（方块、竖线或下划线；常亮或闪烁）和窗口本身——终端周围的内边距，
以及让窗口在桌面之上半透明的背景不透明度与模糊。应用自身的界面留在 **外观** 里：侧栏的
字体与密度。

## 其余的设置

其他标签页覆盖应用的剩余部分：

- **Termio server** —— 排在侧栏第一位，名字下方显示本机的状态：本机自己的 Termio server，
  以及 `termio` [命令行工具](/zh-CN/docs/cli)的开关。见 [Termio server](/zh-CN/docs/server)。
- **通用** —— 语言、检查器 Issues 面板背后的 GitHub 集成，以及一个用于匿名每日使用统计
  的隐私开关。
- **终端** —— 除了字体、光标和窗口，还有回滚历史与文本选择。
- **远程主机** —— 你从这儿能连上的每一台机器，一台一行，点进去是它的连接方式和
  Termio 在它上面装了什么。见 [设备](/zh-CN/docs/devices)。
- **工作区** —— 每个工作区连同它所在的设备，也是重命名和移除工作区的地方。见
  [工作区](/zh-CN/docs/workspaces)。
- **键盘** —— 重新绑定任意快捷键；参见 [键盘快捷键](/zh-CN/docs/keyboard)。
- **Agent** —— 添加 Agent、启用它们，并打开
  [会话控制](/zh-CN/docs/session-control)，以及设置任务完成通知。按设备不同的那些值——
  CLI 装在哪儿、在不在——会在这个 Agent 自己的页面上每台设备一行地列出来，而不是藏在一个
  选择器后面。
- **手机** —— 把 iPhone 和某台机器配对，并发布一个它能连上的地址。见
  [iOS 应用](/zh-CN/docs/iphone)。
- **社区** —— 在哪里找到这个项目：GitHub、Discord 和微信群。

设备是一行一行列出来的，从来不是一个选择器。一个按设备不同的设置，会在它该在的地方每台
设备一行地列出来——命令路径就在那个 Agent 自己的页面上——而一台设备的完整情况是靠导航到达
的：本机用 **Termio server**，其他设备用**远程主机**下的一行。
