用 `⌘,` 打开 **设置**。这是一个标准的 macOS 设置窗口，左侧一列标签页；**外观** 就是
终端长相所在的地方。

## 主题

Termio 使用 Ghostty 格式的主题，所以 Ghostty 主题生态里的东西都能用。在
**设置 ▸ 外观** 里各选一个浅色和深色主题，Termio 会跟随系统在两者之间切换。

如果你本来就在用 Ghostty，全新安装时其实不用挑：Termio 首次启动会读取你的
`~/.config/ghostty/config`，直接沿用你在那里选好的字体和主题。

想以你自己的终端为预览来浏览整个目录，打开命令面板（`⇧⌘P`）并选择 **更改主题…**——
在列表里上下移动会实时给你打开的终端重新上色，回车保留，Esc 还原。

要加入你自己的主题，把 Ghostty 的 `.toml` 主题文件放进：

```
~/Library/Application Support/termio/Themes/
```

**打开主题文件夹** 按钮会直接带你过去，**重新加载** 会在不重启的情况下识别新文件。

## 字体

选择你 Mac 上任意一款等宽字体，设定字号，如果偏好更重的笔画可以打开 **加粗字形**。
字号也有工作时可用的实时快捷键——`⌘=` 变大，`⌘-` 变小，`⌘0` 还原。

## 光标与窗口

同一个标签页还能调光标（方块、竖线或下划线；常亮或闪烁）和窗口本身——终端周围的内边距，
以及让窗口在桌面之上半透明的背景不透明度与模糊。应用自身的界面也在这里：侧栏的字体与
密度。

## 其余的设置

每一项设置、它的默认值，以及背后的 `settings.json` 键，都列在[设置参考](/docs/settings)里。
简单说，其他标签页包括：

- **通用** —— 安装 [`termio` 命令行工具](/zh-CN/docs/session-control)，并选择 Termio
  是否安装它的 Agent 技能、是否发出任务通知。
- **终端** —— 回滚历史与文本选择。
- **SSH** —— 你 `~/.ssh/config` 里的主机，带一个「测试连接」探测。Termio 把那个文件当作
  事实来源，绝不背着你改写它。
- **键盘** —— 重新绑定任意快捷键；参见 [键盘快捷键](/zh-CN/docs/keyboard)。
- **Agent** —— 添加 Agent、启用它们，并打开
  [会话控制](/zh-CN/docs/session-control)。
- **用量** —— 你已登录的 Agent（Claude Code、Codex）的 token 用量。Termio 复用各个命令行
  工具自己的凭据，告诉你离额度还有多远；它本身不存任何东西。
- **移动设备** —— [iPhone 伴侣应用](/zh-CN/docs/iphone) 的配对与远程访问。
- **社区** —— 在哪里找到这个项目：GitHub、Discord 和微信群。
