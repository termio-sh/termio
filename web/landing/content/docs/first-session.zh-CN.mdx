Termio 里的*会话*就是一个真实终端，跑着一件事——一个 Agent、一个开发服务器，或者
一个普通 shell。下面是从刚启动到搭好工作台的完整路径。

## 打开项目

在欢迎界面选择 **打开项目**，挑一个文件夹。Termio 会把它加进侧栏，并记在 **最近**
里方便下次打开。项目就是一个工作目录——你在其中启动的 Agent 都从这里开始。

## 启动一个 Agent

选中项目后新建会话，挑一个 Agent——Claude Code、Codex、Gemini，或任何你装过的命令行
工具。Termio 会在项目根目录用真实终端打开它。你像在任何终端里一样输入；Agent 的 TUI
原生渲染。

侧栏会显示会话的实时状态——**工作中**、**空闲**、**完成**，或**需要你**。
[核心概念](/zh-CN/docs/concepts#status) 解释了这四种状态；要留意的是**需要你**，
它意味着 Agent 被提问或权限确认挡住了，没有你就无法继续。

<Callout type="tip">
  在一个会话里发起长任务，切到另一个会话，让侧栏在第一个 Agent 需要你时立刻告诉你。
</Callout>

## 拆分窗口

真实的工作往往需要不止一个窗格。用 `⌘D` 向右拆分当前窗格，或用 `⇧⌘D` 向下拆分，
然后把另一个会话放进新窗格——一个跑 Agent，一个跑开发服务器，再来一个 shell。窗格
以树的形式平铺，所以你可以嵌套出任意布局。

要重新排布，把指针移到窗格标题栏上，拖动出现的抓取手柄。高亮会预示窗格将落在哪里：
放到另一个窗格的左半、右半、上半或下半，就把它放到那一侧；放在正中则把两个窗格互换。

<DocsVideo
  src="/screenshots/docs/21-rearrange-pane.mp4"
  poster="/screenshots/docs/21-rearrange-pane-poster.png"
  label="一个 Termio 窗格被抓起、拖到另一个窗格上，再放到新的位置"

用 `⌥⌘` 加方向键在窗格间移动焦点，用 `⇧⌘↩` 把当前窗格临时放大到填满窗口。`⌘W` 是
**取消编组**——会话会独立继续运行，而不是被结束。每个快捷键都可以重新绑定——参见
[键盘快捷键](/zh-CN/docs/keyboard)。

## 关于会话的生命周期

会话是活着的进程，不是保存下来的记录。你退出 Termio 时，shell 和 Agent 都会随之退出
——重新打开应用是全新开始。只读的会话轨迹（见 **信息** 面板）会保留一份渲染后的记录，
但正在运行的进程本身撑不过一次退出。

<DocsImage
  src="/screenshots/docs/24-info-trace.png"
  alt="Termio 信息检查器在终端旁显示会话元数据和只读轨迹"
  width={2424}
  height={1664}
/>

<Callout type="warning">
  退出 Termio 会结束所有正在运行的 Agent 和 shell。长任务无法在应用重启后存活——它们
  工作时请让 Termio 保持打开。
</Callout>
